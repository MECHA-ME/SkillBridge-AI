# SkillBridge AI 🚀

## From Skill to Salary to Startup

SkillBridge AI is a predictive economic mobility ecosystem designed to transform users from unskilled individuals into empowered professionals and micro-entrepreneurs. Built in alignment with **UN Sustainable Development Goal 8 (Decent Work and Economic Growth)**, the platform leverages **Artificial Intelligence, Blockchain, and Predictive Analytics** to bridge skill gaps, unlock employment, and create verifiable pathways to sustainable economic success.

---

# 🌟 Overview

SkillBridge AI addresses one of the world’s most pressing challenges: the disconnect between skills, employment opportunities, and economic mobility. Traditional systems are fragmented, reactive, and inaccessible to millions of students, gig workers, rural youth, and informal laborers.

Our ecosystem creates a unified pathway:

## **Unskilled → Skilled → Employed → Entrepreneur**

# 🚦 Getting Started

## Prerequisites

* Node.js (v18 or higher)
* npm or yarn
* Google Gemini API Key

---

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/your-username/skillbridge-ai.git
cd skillbridge-ai
```

### Install Dependencies

```bash
npm install
```

### Environment Configuration

Create a `.env` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### Run Development Server

```bash
npm run dev
```

### Local Access

```bash
http://localhost:3000
```
